# ZUMI — Flow with your people.

Zumi is a community-first social platform that combines content creation, short-form video, community building, and a native coin economy (**Drops**) into a single cohesive product.

## Platform Vision
Designed from day one for monetization, Zumi ensures that every engagement action — watching a Wave, joining a Circle, or completing a challenge — provides economic opportunity for creators.

## Project Structure
This is a monorepo containing the following components:

- **[backend/](backend/README.md)**: Laravel 11 API and Filament Admin Dashboard.
- **frontend/**: (Coming Soon) Next.js 14 client application.

## Core Pillars
- 🌊 **Flow**: Effortless and natural user experience.
- 🤝 **Community**: People come for content, stay for belonging.
- 💰 **Earning**: Native economy (Drops) for transparent monetization.
- 🛡️ **Trust**: Immutable ledger and creator-first policies.

## Tech Stack (Overview)
- **Backend**: PHP 8.4, Laravel 11, PostgreSQL, Redis.
- **Frontend**: TypeScript, Next.js 14, TailwindCSS.
- **Infrastructure**: Cloudflare R2/Stream, Stripe Connect, LiveKit.
